# Prototype: target filter in script generation

Status: prototype-ready
Blocked by: –
Spec: ../spec.md
Type: prototype

## What

Throwaway HTML mockup of the script generation page with: (1) Zone checkboxes (all checked by default), (2) Machine Tag checkboxes (from inventory), (3) AND/OR toggle, (4) live count of matching Machines/Interfaces. Integrated into the existing generation flow, between profile selection and the generate button.

## Acceptance

- the user clicks through: check a Zone, check a Tag, toggle AND/OR, see the count change
- UX feels like a natural step in the existing generation flow, not a separate screen

## What

Throwaway HTML mockup of the Automations page: (1) list of existing Automations with label, action, condition, (2) add/edit modal with the hybrid editor (visual mode: field/operator/value dropdowns + AND/OR; text mode: free text with autocomplete), (3) test button showing match count. Fake data, offline.

UX reference: Wireshark display filter bar for the text mode, Notion/Airtable filter builder for the visual mode.

## Acceptance

- the user clicks through, creates a tag Automation and an exclusion, switches between visual and text mode
- autocomplete feels responsive and suggests relevant values
- the user validates the UX before implementation begins
